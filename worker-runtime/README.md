# Reins worker runtime source

This is an installable snapshot of the Reins runtime needed by `reins control experiment-worker`. It contains proprietary Reins code and is supplied for this UK geography pilot under the included `LICENSE`. It does not contain server credentials, provider keys, customer data, or an evaluation dataset.

Install from the parent kit with `python -m pip install ./worker-runtime`. The executable is `reins`. See the parent `README.md` before starting a worker.
